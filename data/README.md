# 로컬 입력 자료

학습 자료와 차트 원본은 이 저장소에 배포하지 않습니다.

차트 노트북에는 `rank`, `date`, `song`, `artist`, `last_week`, `weeks_on_chart` 컬럼이 있는 CSV가 필요합니다. 원본 배분 과정을 실행하려면 1990년대 선별·곡명 중복 제거 후 최소 300행이 있어야 합니다.

MIDI 노트북에는 [제작 규칙](../docs/data-preparation.md)을 참고해 직접 만든 단일 트랙 MIDI를 업로드하세요. Colab의 임시 저장소에 올린 입력과 `outputs/`의 결과는 런타임이 종료되면 사라질 수 있습니다.
