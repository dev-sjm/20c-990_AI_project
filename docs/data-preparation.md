# MIDI 학습 자료 제작 규칙

팀이 사용한 `Bill_Board/Instruction.docx`의 내용을 공개용으로 정리했습니다. 원본 문서는 연락처나 내부 메모와 함께 별도로 보관하며, 여기에는 음악 데이터 제작 기준만 담았습니다.

## 곡 선정과 카피

팀원 4명이 1990년대 빌보드 곡에서 중요하다고 판단한 부분을 직접 MIDI로 카피했습니다. 작업 지침은 코러스 중심으로 작성되었으며, 규칙에 맞추기 어려운 곡은 보류하도록 했습니다.

| 요소 | 제작 기준 |
| --- | --- |
| 박자 | 4/4 |
| 템포 | 120 BPM |
| 길이 | 8마디 |
| 트랙 | 단일 트랙 MIDI |
| 시간 단위 | 16분음표보다 잘게 나누지 않음, 모든 음 퀀타이즈 |
| 조성 | 장조는 C major, 단조는 A minor로 조옮김 |
| 벨로시티 | 80 |
| 화성 | 3화음, 4분음표보다 잘게 나누지 않음 |
| 코드 길이 | 다음 코드 전까지 유지, 코드가 바뀌면 같은 음도 다시 시작 |

보이싱은 원곡의 간단한 피아노 버전을 기준으로 하며, 전위를 허용했습니다. 멜로디는 레가토를 강제하지 않았습니다. 지침에는 못갖춘마디가 아닌 코러스는 두 번째 마디부터 시작하도록 되어 있으나, 검사용 코드의 9마디 처리 조건과 완전히 같은 명세는 아닙니다.

## 음역 분리

지침은 코드와 멜로디 사이에 비어 있는 한 옥타브를 두도록 했습니다. 원본 문서에서는 가온다를 C3로 표기하므로, 다른 DAW의 옥타브 이름과 혼동하지 않도록 MIDI 번호를 함께 확인해야 합니다.

검사용 코드가 제거 대상으로 준비한 행은 MIDI 0–35, 60–71, 112–127입니다. 이를 제거하면 64개 음높이 행이 남지만, **실제 검사 화면에서는 삭제 명령이 주석 처리되어 전체 128개 행을 표시합니다.** 추가 확보된 데이터 제작 노트북에서 이 행을 실제로 삭제하고 시간축을 4마디씩 분할하는 구현을 확인했습니다.

## 저장 규칙

파일명은 `이름_곡명_아티스트.mid` 형식을 사용했습니다. 팀별 CSV의 곡명·아티스트 표기를 복사해 카피 대상과 연결했습니다. 작업 목록의 행 수와 완성된 MIDI 수, 학습에 사용한 이미지 수는 서로 다른 지표입니다.

기존 곡의 카피 자료는 공개 저장소에서 제외했습니다. 노트북을 확인할 때는 직접 제작한 MIDI를 사용하세요.
