# 자료 출처와 공개 범위

팀 구성, 개발 담당, 실제 곡별 작곡 분담, Colab 사용, 차트 크롤링과 DCGAN 접근은 개발자 신재명의 설명에 근거합니다. 발매일과 크레딧은 [벅스 앨범 페이지](https://music.bugs.co.kr/album/20528080?wl_ref=list_tr_11_ar)를 참고했습니다. 프로젝트명은 개발자 요청에 따라 22c-990을 유지하며 음원 서비스의 표기는 별도로 안내합니다.

2022년 8월 11일 기획 문서는 배경과 데이터 제작 계획을 확인하는 자료입니다. 계획의 모든 활동을 완료 성과로 표현하지 않았고, 최종 역할은 개발자 설명을 우선했습니다.

## 공개용 편집

원본을 변경하지 않고 별도의 공개용 복사본을 만들었습니다.

- 실행 출력·오디오·메타데이터·실행 번호를 제거하고 개인 Drive 루트를 치환했습니다.
- 01 차트의 pandas append 반복을 같은 행의 직접 선택으로 바꿨습니다.
- 03 데이터 제작은 디버그 셀을 제외하고 함수를 실행 순서로 정리했습니다.
- 04 학습은 실험용 후반 셀을 제외하고 입력 검사·디렉터리 생성·시작 플래그·종료 시 저장을 추가했습니다. 이미지 파일명을 실제 epoch로 수정하고 그림을 닫도록 했습니다.
- 05 추론은 체크포인트 파일·복원 상태 확인과 출력 경로를 추가하고 오디오를 선택 과정으로 분리했습니다.
- 모델 구조와 음악 변환의 핵심 알고리즘은 보존했습니다.
- 서로 다른 원본 8개는 archive에 보관했습니다. 실험 셀 순서를 보존했으므로 순차 실행을 보장하지 않습니다.

기반 TensorFlow 튜토리얼은 복제하지 않고 [출처와 라이선스](../THIRD_PARTY_NOTICES.md)로 연결합니다.

## 제외 자료

원곡 카피 MIDI, 차트 CSV·팀별 CSV, 학습 배열, 체크포인트, 데모 오디오, 연락처가 있는 내부 문서와 전체 생성 이미지 묶음은 제외했습니다. 코드에 예제 파일명이 남아 있을 수 있으나 해당 데이터는 포함하지 않습니다.

README 이미지 한 장은 당시 생성 이미지의 복사본이며 모델 평가나 발매곡 악보로 제시하지 않습니다. TensorFlow 기반 코드의 기존 라이선스를 유지하고 프로젝트 고유 자료에 별도 재사용 라이선스를 추가하지 않았습니다.
