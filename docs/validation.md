# 검증 기록

공개용 정리 시 2026년 9월 10일 아래 검사를 실행했고 **5개 모두 통과**했습니다.

| 검사 | 확인한 내용 |
| --- | --- |
| 노트북 형식 | 13개 노트북의 nbformat 유효성, 출력·실행 번호 제거, 정리본 5개의 Python 문법 |
| 차트 배분 | 가상의 320곡으로 원본의 행 선택과 팀별 배분 확인 |
| MIDI → 이미지 | 직접 만든 MIDI로 음역 매핑과 앞·뒤 4마디 분할 확인 |
| 이미지 → MIDI | 음높이·시작 시각·길이, 마지막 시간 칸의 단음과 지속음, 실제 MIDI 저장·재읽기 |
| 모델 정의 | 학습본과 배포본의 생성자·판별자 정의가 같은지 구문 트리로 비교 |

검사에는 기존 곡의 카피 자료를 사용하지 않습니다. 테스트 입력은 실행할 때 직접 구성합니다.

```bash
python -m pip install -r requirements-validation.txt
python -m unittest discover -s tests -v
```

검증 환경은 Windows, Python 3.12입니다. 패키지 목록은 가벼운 검증용이며 당시 학습 환경을 고정한 파일이 아닙니다.

이번 정리에서 장시간 DCGAN 학습, TensorFlow로 실제 체크포인트 복원, GPU 실행, Colab 전체 순차 실행, FluidSynth 오디오 렌더링은 수행하지 않았습니다. 모델 정의 비교는 가중치 복원이나 생성 품질을 보장하지 않습니다. 이 범위는 원본 체크포인트·환경과 함께 별도로 검증해야 합니다.
